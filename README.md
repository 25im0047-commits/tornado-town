# TORNADO TOWN

竜巻を動かし、街を巻き込むほど大きくなる3Dゲームの試作です。2分30秒以内にサイズ6へ成長し、中央の時計塔を巻き込むとクリア。終了後は、時間制限なしで街を続けられます。

## 遊び方

`TORNADO-TOWN.html` がゲーム本体です。Three.js、スタイル、ゲームコードを埋め込んだ単一ファイルで、外部CDNや追加素材のダウンロードは必要ありません。通常はこのHTMLをChrome、Edge、Safariなどのブラウザーで開きます。

このMacでは `遊ぶ.command` からも開けます。起動用スクリプトの実行をOSが制限する場合は、HTMLをブラウザーで直接開いてください。

| 操作 | 内容 |
| --- | --- |
| WASD / 矢印キー | 画面の向きに沿って移動 |
| 画面をドラッグ | 押した場所から動かした方向へ移動 |
| Space / 右下の「突風」 | 一時的に移動速度と巻き込み範囲が増加。7秒で回復 |
| Esc / 右上の一時停止 | 停止・再開 |
| 右上の音ボタン | 音のオン・オフ。初期状態はオン |

木・街灯 → 車 → 家 → 商店・マンション → 高層ビル → 時計塔の順に巻き込める物が増えます。今巻き込める物は画面左上、時計塔と現在位置は左下の地図に表示します。

## 演出の強化

- 鮮やかな街と、太い黒縁の見出し・数字。
- 建物を巻き込むと加点と擬音が飛び出し、星・紙吹雪・衝撃波・集中線が広がります。
- 大物の吸収と巨大化に合わせた画面揺れと短いズーム。操作表示は固定したままにしています。
- 2.5秒以内に次の物を巻き込むとコンボが続き、20連続で7秒間のフィーバー。吸引範囲は1.2倍、移動速度は1.18倍になります。
- コンボに応じて音程が上がる巻き込み音、建物の破壊音、突風、巨大化・フィーバー・クリアのジングル。BGMはフィーバー中にテンポが上がります。
- OSの「動きを減らす」設定では集中線、画面揺れ、ズームを抑えます。

## 成長とカメラの調整

レベルアップに必要な累積の吸い込み量を増やしました。個数ではなく、木・車・建物それぞれの重みで加算する量です。

| 到達サイズ | 以前 | 現在 |
| --- | ---: | ---: |
| 2 車 | 16 | 50 |
| 3 家 | 55 | 180 |
| 4 商店・マンション | 145 | 520 |
| 5 高層ビル | 330 | 1250 |
| 6 時計塔 | 650 | 2600 |

カメラは小型時ほど近く・低く、巨大化するほど距離を引きます。16:9の画面では距離26から85.8へ変化し、最終的な見渡せる幅は最初の約3.3倍になります。縦長画面では竜巻の全体が収まるよう少し引きます。

## 実装

- Three.js r180 / WebGLによる立体描画。実行時の外部依存は同梱ライブラリーのみ。
- 49街区の住宅、商店、高層ビル、公園、道路、海岸、森林、山、時計塔を独自の形状と色で生成。
- 同じ形状の建物・小物はまとめて描画。巻き込んだ物だけを別のメッシュに切り替え、浮上・周回・縮小を動かす。
- 動く竜巻の形状と縞、5本の風の帯、110枚の砂ぼこり、最大420個の破片、地面に残る跡、成長に追従するカメラ。
- 大きな物体の同時巻き上げは42個まで。使い終わった表示を再利用し、長く遊んでも増え続けない構成。
- ゲーム開始時に、ブラウザー内で生成したBGM・風音・巻き込み音を再生。音は右上で切り替えられます。

建物が飛ぶ動きは演出用の軌道制御です。実際の流体計算、建物の構造破壊、完全な物理シミュレーション、オンライン対戦は実装していません。

## 開発と確認

Node.js 20以降で実行できます。パッケージのインストールは不要です。

```sh
npm run build
npm test
npm run dev
```

プレビューは `http://127.0.0.1:8893` です。このMac内だけで待ち受けます。プレビューを終了するには、起動したターミナルでCtrl+Cを押します。自動起動や定期実行は設定していません。

`src/core.mjs` が成長・判定・時間・移動のルール、`src/main.js` が街・描画・入力・画面表示、`src/juice.js` が画面上の粒子・文字・集中線、`src/audio.js` が音の生成、`src/style.css` がUI、`build.mjs` が単一HTMLの生成です。

実際の確認内容と制限は `PROGRESS.md`、設計の判断と修正理由は `MEMORY.md`、参照した実装と利用条件は `RESEARCH.md` と `THIRD_PARTY_NOTICES.txt` に記載しています。
